# 무한궤도(하부주행체)의 정의와 중요성

meta: 006 | 서술형(25점) | 일반 기계 지식

## I. 개요

### 1. 정의
차체 하중을 **연속된 궤도(Track)를 통해 넓은 면적으로 분산 지지**하면서
구동력을 전달하는 주행 장치로, 굴삭기·도저 등 토공 기계의 표준 주행 방식이다.

### 2. 중요성

| 관점 | 내용 |
|---|---|
| 기능 | **접지압 저감**으로 연약지반 주행 가능 |
| 성능 | 큰 접지면적 → **높은 견인계수** 확보 |
| 경제성 | 건설기계 **정비비의 40~60%가 하부주행체**에서 발생 |
| 안정성 | 낮은 무게중심과 넓은 지지면으로 전도 안정성 우수 |

> **답안 포인트** — "하부주행체는 장비 수명주기 비용(LCC)의 최대 항목"이라는
> 사실을 제시하면 단순 구조 설명을 넘어 관리 관점을 보여줄 수 있다.

## II. 구조 및 작동원리

### 1. 구성

```
                    ┌── 트랙 프레임 ──┐
        상부롤러 ●            ●
     ┌───────────────────────────────────┐
     │  ◎                             ◎  │
   아이들러                        스프로킷
   (유동륜)                        (기동륜)
     │  ○    ○    ○    ○    ○    ○     │
     └──────── 하부롤러(트랙롤러) ───────┘
     ╚═══════════════════════════════════╝
              트랙 슈 + 링크 + 핀·부싱

   동력 전달 : 유압모터 → 감속기 → 스프로킷 → 트랙 링크 → 지면 반력
```

| 부품 | 기능 | 주 손상 형태 |
|---|---|---|
| 스프로킷 | 동력 전달, 트랙 구동 | 치면 마모(훅 형상) |
| 아이들러 | 트랙 유도, 장력 조절 | 플랜지 편마모 |
| 하부롤러 | 차체 하중 지지 | 외경 마모, 시일 누유 |
| 상부롤러 | 트랙 상부 처짐 방지 | 외경 마모 |
| 트랙 슈 | 접지, 견인력 발생 | 그로우저 마모, 볼트 이완 |
| 링크·부싱 | 트랙 연결, 스프로킷 물림 | **부싱 외경 마모(수명 지배)** |

### 2. 접지압의 원리

```
                    W (차체 총중량)
                      ↓↓↓↓↓↓
   ┌──────────────────────────────────────┐
   │              트랙 슈                  │
   └──────────────────────────────────────┘
   ◀────────── 접지길이 L ────────────────▶
            슈 폭 B

              W
   접지압 p = ─────────   (kgf/cm²)
             2 · B · L

   ※ 좌우 2개 궤도이므로 분모에 2
```

| 장비 | 접지압 | 비교 |
|---|---|---|
| 사람 | 약 0.5 kgf/cm² | 기준 |
| 타이어식 로더 | 2.5~4.0 kgf/cm² | 연약지반 침하 |
| **무한궤도 굴삭기** | **0.3~0.6 kgf/cm²** | 연약지반 주행 가능 |
| 습지용(광폭 슈) | 0.2 kgf/cm² 이하 | 초연약지반 |

→ 무한궤도 장비의 접지압은 **사람이 서 있을 때와 비슷한 수준**이며,
   이것이 연약지반 시공을 가능케 하는 핵심이다.

### 3. 견인력  F = W · μ (μ : 견인계수)

| 노면 조건 | 무한궤도 μ | 타이어 μ |
|---|---|---|
| 건조 사질토 | 0.90 | 0.60 |
| 점토(습윤) | 0.70 | 0.40 |
| 습지·연약 | **0.50** | 0.20 |
| 암반 | 0.55 | **0.65** |

연약지반일수록 무한궤도의 우위가 커지며, 암반·포장로에서는 기동성 면에서
타이어식이 유리하다.

## III. 트랙 장력 관리

### 1. 장력의 영향

```
  부품 수명
   ▲
   │        ╭───●───╮  ← 최적 장력 구간
   │      ╱           ╲
   │    ╱               ╲
   │  ╱                   ╲
   │╱                       ╲
   └──┬──────────┬───────────┬──▶ 트랙 장력
    이완        적정        과장력

  [이완] 트랙 탈선(De-track), 슈 이탈,
         스프로킷 치면 충격 마모
  [과장력] 부싱·핀 면압 급증, 롤러 베어링 부하 증대,
         주행 저항 증가 → 연비 악화, 수명 30~50% 단축
```

### 2. 점검 방법

```
        상부롤러                    상부롤러
           ●                           ●
   ════════╧═══════╲            ╱══════╧════════
                    ╲__ ↕ a  __╱
                      처짐량

   · 평탄지에 정차 후 상부롤러 사이 최대 처짐량 a 측정
   · 규정값 : 일반 20~30 mm (기종별 정비지침서 확인)
   · 조정 : 그리스식 텐셔너에 그리스 주입/배출
   · ※ 배출 시 그리스가 고압으로 분출 → 밸브를 1회전 이상 풀지 말 것
```

### 3. 토질별 장력 조정

| 토질 | 장력 설정 | 이유 |
|---|---|---|
| 사질토·암반 | 약간 팽팽하게 | 이물 유입 적음, 탈선 방지 우선 |
| 점토·습지 | **느슨하게** | 토사 협착 시 장력 급증 방지 |

## IV. 마모 및 수명 관리

### 1. 마모 측정 항목

| 부품 | 측정 항목 | 폐기 기준(예) |
|---|---|---|
| 링크 | 높이 | 신품 대비 마모 100% |
| **부싱** | 외경 | 마모 100% 시 **회전(Turn) 1회 가능** |
| 슈 | 그로우저 높이 | 신품 대비 80% 마모 |
| 스프로킷 | 치면 형상 | 훅 형상 발생 시 |
| 롤러·아이들러 | 외경 | 플랜지 접촉 시 |

### 2. 부싱 회전(Bushing Turn)

```
   [초기]            [마모 후]           [180° 회전]
    ╭───╮             ╭───╮               ╭───╮
    │ ○ │             │ ○▓│               │▓○ │
    ╰───╯             ╰───╯               ╰───╯
   원형 단면      스프로킷측만 마모     반대면 사용 → 수명 2배

   · 부싱은 스프로킷과 물리는 한쪽 면만 집중 마모
   · 마모 한계 도달 시 180° 회전시켜 재사용 → 교체비 50% 절감
   · 회전 시기를 놓치면 관통 마모되어 회전 불가 → 전량 교체
```

## V. 문제점 및 대책

| 현상 | 원인 | 대책 |
|---|---|---|
| **트랙 탈선** | 장력 이완, 아이들러 정렬 불량, 급선회 | 장력 정기 점검, 정렬 측정, 급선회 자제 |
| 편마모 | 아이들러·스프로킷 직진도 불량, 편경사지 반복 주행 | 정렬 확인, 작업 방향 교대 |
| 롤러 누유 | 플로팅 시일 손상 | 조기 발견·교환(베어링 소착 방지) |
| 조기 마모 | 토사·자갈 협착, 세척 미흡 | **작업 후 트랙 내부 이물 제거** |
| 슈 볼트 이완 | 초기 이완, 규정 토크 미준수 | 신품 장착 후 50 h 재조임, 토크 관리 |

### 수명 연장을 위한 운전 관리
급선회(제자리 회전) 최소화 → 후진 주행 비율 축소 → 경사지 횡방향 주행 회피
→ 작업 종료 후 이물 제거 → 장거리 자주 주행 대신 트레일러 운반.
이 중 **급선회 억제**가 부싱·슈 마모에 가장 큰 영향을 미친다.

## VI. 결론

1. 무한궤도는 **접지압을 0.3~0.6 kgf/cm² 수준으로 낮춰** 연약지반 주행과
   높은 견인력을 동시에 확보하는 장치로, 토공 기계의 성능 기반을 이룬다.

2. 그러나 하부주행체는 **장비 정비비의 40~60%를 차지**하는 최대 비용
   항목이므로, 구조 이해보다 관리 기법의 실행이 경제성을 좌우한다.
   특히 **트랙 장력 관리**는 비용이 들지 않으면서 부품 수명을 30~50%
   좌우하는 가장 효과적인 수단이다.

3. 부싱 회전(Turn) 시기를 놓치지 않는 것이 교체비 절감의 핵심이며,
   이를 위해 마모량 정기 측정을 정비 계획에 편입해야 한다.

4. 향후 **마모 센서와 텔레매틱스를 연계한 하부주행체 수명 예측**이
   보편화되면, 계획 정비를 통해 돌발 정지를 예방하고 부품 조달
   리드타임을 확보할 수 있을 것으로 판단된다.
