# 로드롤러의 다짐 원리와 유지관리

meta: 077 | 서술형(25점) | 특수 건설기계

## I. 개요

### 1. 다짐(Compaction)의 정의
흙·아스팔트에 **외력을 가해 공극을 줄이고 밀도를 증대**시켜 지지력과
안정성을 확보하는 작업으로, 도로·성토 공사의 품질을 결정하는 핵심 공정이다.

### 2. 다짐의 목적

| 목적 | 효과 |
|---|---|
| 지지력 증대 | 노상·노반 CBR 향상, 포장 두께 절감 |
| 압축 침하 방지 | 준공 후 부등침하·포트홀 방지 |
| 투수성 감소 | 우수 침투 차단 → 동상·연약화 방지 |
| 전단강도 증대 | 사면 안정성 확보 |

## II. 다짐의 원리

### 1. 다짐 에너지의 3요소

```
   ┌── 정적 하중 (Static) ── 자중에 의한 압력
   │      · 머캐덤·탠덤 롤러
   │      · 점성토에 유효
   │
   ├── 진동 (Vibration) ──── 편심추 회전에 의한 기진력
   │      · 진동롤러
   │      · 사질토에 매우 유효 (입자 재배열)
   │
   └── 반죽 (Kneading) ───── 타이어 변형에 의한 전단
          · 타이어롤러
          · 아스팔트 표면 마무리에 유효
```

### 2. 진동 다짐의 메커니즘

```
        편심추 회전                    지반 거동
   ┌──────────────────┐
   │   ●  편심추       │         진동 전        진동 후
   │  ╱ ╲  회전        │        ○ ○ ○ ○       ○○○○
   │ ╱   ╲             │        ○   ○  ○      ○○○○○
   │╲    ╱  기진력 F   │   ──▶   ○ ○   ○   ──▶ ○○○○
   │ ╲  ╱      ↕       │        ○  ○ ○        ○○○○○
   └──┴──┴────────────┘        공극 大          공극 小

   기진력  F = m · e · ω²
     m : 편심추 질량, e : 편심량, ω : 각속도(2πn/60)

   → 회전수의 제곱에 비례하므로 진동수 조절이 다짐력에 지배적
```

## III. 로드롤러의 종류와 적용

| 종류 | 다짐 방식 | 적용 대상 | 특징 |
|---|---|---|---|
| **머캐덤 롤러** | 정적, 3륜 | 기층·노반 | 초기 다짐, 쇄석 파쇄 |
| **탠덤 롤러** | 정적, 2축 | 아스팔트 2차 다짐 | 평탄성 확보 |
| **진동 롤러** | 정적 + 진동 | **사질토, 노체** | 다짐 효율 최고, 층두께 大 |
| **타이어 롤러** | 정적 + 반죽 | 아스팔트 마무리 | 표면 치밀화, 접지압 조절 가능 |
| **탬핑 롤러** | 정적 + 관입 | 점성토 심층 | 돌기로 깊은 층 다짐 |

### 시간당 작업량 산정

```
        1000 · W · L · D · E
   Q = ──────────────────────  (m³/h)
                N

   W : 유효 다짐폭(m) = 롤러폭 − 중복폭
   L : 작업속도(km/h)  ※ 진동롤러 2~4 km/h
   D : 1층 다짐두께(m)
   E : 작업효율 (0.6~0.8)
   N : 다짐 횟수(회)
```

## IV. 다짐 관리 기준

### 1. 다짐도 판정

| 시험법 | 내용 | 기준 |
|---|---|---|
| **들밀도 시험**(모래치환법) | 현장 건조밀도 / 실내 최대건조밀도 | 노상 95%, 노체 90% 이상 |
| 평판재하시험(PBT) | 지지력계수 K값 측정 | K₃₀ ≥ 규정값 |
| 프루프 롤링 | 덤프 주행 후 변형 육안 확인 | 이상 변형부 재시공 |
| CBR 시험 | 관입 저항 | 설계 CBR 이상 |

### 2. 다짐 횟수와 밀도

```

    │           ╱

    │     ╱

    └──┬────┬────┬────┬────┬────┬───▶ 다짐 횟수(회)
       2    4    6    8    10   12

  · 초기 2~6회에 밀도가 급증, 이후 완만
  · 과다짐(over-compaction) 시 입자 파쇄·전단면 형성으로 밀도 저하
  · 시험 시공으로 최적 다짐 횟수를 사전 결정
```

## V. 유지관리 및 문제점 대책

| 항목 | 점검 내용 | 주기 / 기준 |
|---|---|---|
| **진동 발생기 오일** | 유량·오염도 | 1,000 h 교환, 전용 유종 |
| 드럼 스크레이퍼 | 마모·간극 | 매일, 간극 3~5 mm 유지 |
| 살수 장치 | 노즐 막힘, 탱크 | 매일 세척 / **동절기 완전 배수** |
| 방진 고무 마운트 | 균열·경화 | 500 h, 열화 시 진동이 차체로 전달 |
| 주행 유압모터 | 누유, 드레인량 | 1,000 h |
| 드럼 표면 | 요철·아스팔트 부착 | 작업 후 세척 |

### 주요 트러블

| 현상 | 원인 | 대책 |
|---|---|---|
| 아스팔트 드럼 부착 | 살수 부족, 이형제 미사용 | 살수량 증대, 스크레이퍼 조정 |
| 진동 미발생 | 진동클러치 불량, 유압 저하 | 진동회로 압력 측정 |
| 다짐도 미달 | 함수비 부적정, 층두께 과대 | OMC 조정, 1층 20~30 cm 준수 |
| 표면 균열(헤어크랙) | 과다짐, 온도 부적정 | 다짐 횟수 조정, 시험시공 반영 |
| 방진고무 파손 | 경화·피로 | 정기 교환, 진동 상시 사용 자제 |

## VI. 결론

1. 다짐은 **정적하중·진동·반죽**의 조합이며, 토질에 따라 지배적 요소가
   다르다. 사질토는 진동, 점성토는 정적·반죽이 유효하므로 장비 선정 시
   토질 조건을 우선 고려해야 한다.

2. 다짐 품질은 장비 성능보다 **함수비 관리(OMC ± 2%)와 층두께 준수**가
   좌우한다. 현장에서는 시험 시공을 통해 최적 다짐 횟수와 층두께를
   먼저 확정하고 본 시공에 적용하는 것이 원칙이다.

3. 과다짐은 입자 파쇄와 전단면 형성으로 오히려 밀도를 저하시키므로,
   "많이 다질수록 좋다"는 통념은 경계해야 한다.

4. 최근 **지능형 다짐(ICM, Intelligent Compaction)** 기술이 도입되어
   롤러에 장착된 가속도계로 지반 강성을 실시간 측정하고 GPS와 연계해
   다짐 횟수를 자동 관리하고 있다. 이는 전수 검사 효과를 제공하므로
   품질 신뢰성 향상과 재시공 비용 절감에 크게 기여할 것으로 사료된다.
