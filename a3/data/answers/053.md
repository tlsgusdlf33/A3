# 굴삭기 유압계통 고장진단 절차

meta: 053 | 서술형(25점) | 안전 및 문제 해결

## I. 개요

### 1. 진단의 기본 명제
> **"압력은 부하가 만들고, 속도는 유량이 만든다."**

이 명제가 모든 유압 고장진단의 출발점이다.
- **힘이 부족하다** → 압력 계통 문제 (릴리프, 내부 누설)
- **속도가 느리다** → 유량 계통 문제 (펌프 토출량, 관로 저항)

### 2. 증상의 분류

| 증상 | 1차 의심 계통 |
|---|---|
| 전혀 동작하지 않음 | 파일럿압, 커플링, 작동유 레벨 |
| 힘이 없음(들지 못함) | 릴리프 설정압, 펌프 압력 |
| 속도가 느림 | 펌프 토출량(용적효율), 스트레이너 |
| 자연 하강(드리프트) | 홀딩밸브, 실린더 내부 누설 |
| 떨림·맥동 | 공기 혼입, 캐비테이션 |
| 과열 | 릴리프 상시 작동, 내부 누설 |

## II. 진단 절차 (단계별 플로우)

```
  ┌─────────────────────────────────────────┐
  │ 0. 안전 확보                             │
  │   · 작업장치 지면 접지, 잔압 제거        │
  │   · LOTO(시건·표지), 고임목              │
  └────────────────┬────────────────────────┘
                   ▼
  ┌─────────────────────────────────────────┐
  │ 1. 문진 — 언제부터, 어느 동작, 전 조짐   │
  │   "갑자기"인가 "서서히"인가 → 원인 분기  │
  └────────────────┬────────────────────────┘
                   ▼
  ┌─────────────────────────────────────────┐
  │ 2. 기본 점검 (비용 0, 5분)               │
  │   · 작동유 레벨·색상·냄새                │
  │   · 외부 누유, 필터 차압 지시계          │
  │   · 고장코드(DTC) 판독                   │
  └────────────────┬────────────────────────┘
                   ▼
  ┌─────────────────────────────────────────┐
  │ 3. 난기 운전 (작동유 45~55℃)             │
  │   ※ 냉간 측정값은 신뢰할 수 없음         │
  └────────────────┬────────────────────────┘
                   ▼
  ┌─────────────────────────────────────────┐
  │ 4. 압력 측정 → 힘 계통 판정              │
  └────────────────┬────────────────────────┘
                   ▼
  ┌─────────────────────────────────────────┐
  │ 5. 유량(속도) 측정 → 펌프 성능 판정      │
  └────────────────┬────────────────────────┘
                   ▼
  ┌─────────────────────────────────────────┐
  │ 6. 계통 분리 시험 → 고장부 특정          │
  └────────────────┬────────────────────────┘
                   ▼
              조치 · 재발방지
```

## III. 압력 측정과 판정

### 1. 측정 항목 및 기준값

| 측정 항목 | 측정 조건 | 표준값(예) | 이상 시 판단 |
|---|---|---|---|
| 메인 릴리프압 | 실린더 스트로크 엔드 | 32~35 MPa | 낮으면 릴리프 또는 펌프 |
| 파워부스트압 | 부스트 스위치 작동 | 35~38 MPa | 부스트 솔레노이드 |
| 파일럿압 | 엔진 정격회전 | 3.5~4.0 MPa | 낮으면 조작 불능·반응 둔화 |
| 선회 릴리프압 | 선회 고정 후 조작 | 25~28 MPa | 선회 모터 내부 누설 |
| 주행 릴리프압 | 한쪽 궤도 고정 | 32~35 MPa | 주행 모터 |
| 펌프 드레인량 | 정격 부하 | 규정값 이내 | **2배 초과 시 펌프 오버홀** |

### 2. 릴리프 vs 펌프 판별법 (핵심 기법)

```
   증상 : 메인 릴리프압이 규정보다 낮다

   ┌──────────────────────────────────────────┐
   │ 릴리프 밸브 설정압을 임시로 상향 조정     │
   └───────────┬──────────────────────────────┘
               │
       ┌───────┴────────┐
       ▼                ▼
   압력 상승함      압력 변화 없음
       │                │
       ▼                ▼
  ┌─────────┐      ┌──────────────┐
  │릴리프 밸브│      │ 펌프 성능 저하│
  │  불량    │      │ (용적효율 저하)│
  │(조정/교환)│      │  → 오버홀     │
  └─────────┘      └──────────────┘

   ※ 시험 후 반드시 규정 설정압으로 복원할 것
```

## IV. 증상별 원인 계통도

### 1. 힘이 없다 (들어올리지 못함)

```
 힘 부족 ┬─ 릴리프 설정압 저하 ── 조정 나사 이완, 스프링 피로
         ├─ 릴리프 밸브 고착 ──── 오염물 끼임 → 분해 세척
         ├─ 펌프 용적효율 저하 ── 슈·실린더블록 마모 (드레인량 확인)
         ├─ 실린더 내부 누설 ──── 피스톤 시일 파손
         └─ 컨트롤밸브 내부 누설 ─ 스풀 마모, 간극 확대
```

### 2. 속도가 느리다

```
 속도 저하 ┬─ 펌프 토출량 부족 ── 사판각 제어 불량, 레귤레이터
           ├─ 흡입 저항 증대 ──── 스트레이너 막힘 ← 가장 흔함
           ├─ 작동유 점도 과대 ── 유종 부적합, 저온
           └─ 관로 저항 증가 ──── 호스 내부 박리, 굽힘 과다
```

### 3. 자연 하강(드리프트) 판별

```
   붐을 최대 상승 후 5분 방치 → 하강량 측정

   ┌─────────────────────────────────────┐
   │ 붐 실린더 배관을 플러그로 막고 재시험│
   └──────────┬──────────────────────────┘
              │
      ┌───────┴────────┐
      ▼                ▼
  하강 멈춤        여전히 하강
      │                │
      ▼                ▼
 ┌──────────┐    ┌──────────────┐
 │홀딩밸브 / │    │ 실린더 내부   │
 │컨트롤밸브 │    │ 누설(시일 파손)│
 │  누설     │    │ → 실린더 분해 │
 └──────────┘    └──────────────┘
```

## V. 측정 시 안전 및 주의사항

| 항목 | 내용 |
|---|---|
| 잔압 제거 | 엔진 정지 후 조작레버 수회 왕복, 어큐뮬레이터 방압 |
| 압력계 선정 | 측정 예상값의 **1.5~2배 레인지** (과압 시 계기 파손) |
| 핀홀 누유 | 고압 분출유는 피부 관통(주사상) → **맨손 점검 절대 금지**, 판지 사용 |
| 유온 관리 | 반드시 난기 후 측정 (냉간 시 점도차로 오판) |
| 측정 위치 | 전용 테스트 포트 사용, 배관 임의 분해 금지 |
| 기록 | 측정값·유온·회전수 동시 기록 (추세 관리) |

### 고압 분출 위험

```
   35 MPa 작동유의 핀홀 분출

   ───▶ 0.1mm 핀홀에서 분출 시 유속 200 m/s 이상
        → 피부를 관통하여 조직 내 침투
        → 초기 통증 미미하나 수 시간 내 괴사 진행
        → 즉시 외과 수술 필요 (단순 창상으로 오인 금지)

   점검 시 : 판지(cardboard)를 대고 이동시켜 누유 위치 확인
```

## VI. 결론

1. 유압 고장진단은 감이 아니라 **측정과 기준값 비교**로 수행해야 한다.
   "압력은 부하, 속도는 유량"이라는 원리에서 출발해 증상을 계통별로
   분류하면 진단 범위를 신속히 좁힐 수 있다.

2. 실무에서 가장 효과적인 기법은 **릴리프 설정압 임시 상향에 의한
   릴리프/펌프 판별**과 **배관 차단에 의한 실린더 내부 누설 판별**이다.
   이 두 가지로 고장의 상당 부분을 부품 탈거 없이 특정할 수 있다.

3. 진단 전 **난기 운전과 잔압 제거**는 정확성과 안전의 전제조건이다.
   특히 고압 핀홀 분출은 경미해 보이나 치명적이므로, 맨손 점검 금지를
   작업표준에 명문화해야 한다.

4. 향후 **압력·온도 센서와 텔레매틱스 연계**로 열화 추세를 상시 감시하는
   예지보전(PHM) 체계가 구축되면, 고장 발생 후 진단에서 고장 이전
   예측 정비로 전환될 수 있을 것으로 판단된다.
