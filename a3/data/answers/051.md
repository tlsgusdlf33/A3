# 크레인 작업의 안전 절차 및 재해예방 대책

meta: 051 | 서술형(25점) | 안전 및 문제 해결

## I. 개요

### 1. 크레인 재해의 특성
건설기계 재해 중 **크레인 관련 사고는 사망률이 가장 높은 유형**에 속한다.
전도·붕괴·낙하·협착이 복합적으로 발생하며, 단일 사고로 다수 인명피해가 발생한다.

### 2. 4대 위험요인

| 위험요인 | 발생 기구 | 결과 |
|---|---|---|
| **전도** | 정격하중 초과, 아웃트리거 미전개, 지반 침하 | 기체 전도, 다수 사상 |
| **붕괴** | 붐 좌굴, 과부하, 구조부 결함 | 붐 절손, 낙하 |
| **낙하** | 줄걸이 불량, 후크 해지장치 불량 | 하부 작업자 사망 |
| **감전** | 충전전로 접근 | 감전 사망 |

### 3. 관련 법규
- 산업안전보건기준에 관한 규칙 제132조~제146조 (양중기)
- 건설기계관리법 (정기검사)
- 산업안전보건법 (작업계획서 작성, 신호수 배치)

## II. 전도 안정성의 원리

### 1. 모멘트 평형

```
         ◀───── 작업반경 R ─────▶
                                  ┌───┐
         ╱│                       │하중│ W
        ╱ │                       │   │
       ╱  │                       └─┬─┘
      ╱   │                         │
   ┌─┴────┴─────────────┐           │
   │   크레인 본체 (G)  │           │
   └──┬──────────────┬──┘           │
      ▼              ▼              ▼
   아웃트리거 ──── 전도지점 O ──────────

   안정 모멘트  Ms = G × a   (본체 자중 × 지점까지 거리)
   전도 모멘트  Mo = W × R   (하중 × 작업반경)

   안정 조건 :  Ms ≥ Mo × 안전율
   → 정격총하중 = 안정도와 구조강도 중 작은 값
```

### 2. 작업반경과 정격하중의 관계

```
 정격하중(ton)
  ▲
 50┤██
   │██╲
 40┤███╲
   │████╲
 30┤█████╲
   │██████╲___  ← 안정도 지배 영역
 20┤          ╲___
   │              ╲____
 10┤                   ╲______
   │                          ╲_____
  0┼───┬────┬────┬────┬────┬────┬───▶ 작업반경(m)
   0   5   10   15   20   25   30

  · 작업반경이 2배가 되면 정격하중은 1/2 이하로 급감
  · 붐을 눕힐수록(반경 증가) 위험이 기하급수적으로 증가
  · 반드시 운전실 비치 "정격하중표"로 확인 — 암기·추정 금지
```

> **답안 포인트** — "정격하중은 고정값이 아니라 작업반경의 함수"라는 점을
> 그래프와 함께 제시하면 이해도를 명확히 보여줄 수 있다.

## III. 작업 단계별 안전 절차

### 1. 작업 전

| 항목 | 점검 내용 | 기준 |
|---|---|---|
| 작업계획서 | 하중, 반경, 붐 길이, 이동경로 | 사전 수립·주지 |
| 지반 지지력 | 아웃트리거 접지부 | 침하·연약지반 시 **받침목(깔판) 설치** |
| 아웃트리거 | 전개 상태 | **완전 전개 원칙**, 부분 전개 시 하중 대폭 감액 |
| 수평도 | 수평계 | 경사 1% 이내 |
| 안전장치 | 과부하방지장치, 권과방지장치, 후크 해지장치 | 작동 확인 |
| 와이어로프 | 소선 절단, 직경 감소, 킹크 | 소선 10% 절단 또는 직경 7% 감소 시 **폐기** |
| 충전전로 | 이격거리 | 특별고압 **최소 3 m 이상**(전압별 가산) |

### 2. 작업 중

```
   ┌─────────── 출입금지 구역 설정 ───────────┐
   │                                          │
   │        ╱▔▔▔▔▔╲  붐 선회 반경 전체        │
   │       │  크레인 │                         │
   │        ╲▁▁▁▁▁╱                          │
   │            │                             │
   │         [하중]  ← 하부 통행 절대 금지     │
   │                                          │
   └──── 신호수 1명 지정 (운전자 시야 확보) ───┘
```

- **신호수 1명 지정** — 복수 신호는 혼란·사고의 직접 원인
- 급조작 금지 (급가속·급정지는 진동하중을 유발하여 실하중 증가)
- 하중 하부 및 선회 반경 내 **출입금지**
- 순간풍속 **10 m/s 초과 시 작업 중지**, 15 m/s 초과 시 붐 격납

### 3. 줄걸이(Sling) 작업

```
   줄걸이 각도 θ 와 장력의 관계

        ╱│╲  θ (걸이각)
       ╱ │ ╲
      ╱  │  ╲
     ╱   │   ╲
   ┌─────┴─────┐
   │   하중 W  │
   └───────────┘

   각 로프 장력  T = W / (2 · cos(θ/2))

   | 걸이각 θ | 장력 배수 | 판정 |
   |   0°    |  1.00 W  | 이상적 |
   |  60°    |  1.16 W  | 양호  |
   |  90°    |  1.41 W  | 허용 한계 |
   | 120°    |  2.00 W  | 위험  |
   | 150°    |  3.86 W  | 금지  |

   → 걸이각은 60° 이하 권장, 90° 초과 금지
```

## IV. 안전장치

| 장치 | 기능 | 점검 방법 |
|---|---|---|
| 과부하방지장치 | 정격하중 초과 시 경보·작동 정지 | 정기 작동 시험, **임의 해제 절대 금지** |
| 권과방지장치 | 후크 과다 상승 방지 | 리밋스위치 작동 확인 |
| 후크 해지장치 | 줄걸이 이탈 방지 | 스프링 복귀력 확인 |
| 아웃트리거 인터록 | 미전개 시 붐 조작 제한 | 센서 작동 확인 |
| 경사각 표시기 | 기체 수평 확인 | 영점 확인 |
| 모멘트 리미터 | 실시간 부하율 표시 | 교정 주기 준수 |

## V. 재해 사례 분석 및 대책

| 사고 유형 | 전형적 원인 | 근본 대책 |
|---|---|---|
| 전도 | 아웃트리거 받침목 미설치 → 지반 침하 | 지지력 사전 확인, 깔판 의무화 |
| 붐 절손 | 정격하중표 미확인, 과부하방지장치 해제 | 장치 해제 금지 교육, 부하율 상시 확인 |
| 낙하 | 줄걸이 각도 과대, 해지장치 불량 | 줄걸이 자격자 지정, 각도 60° 이하 |
| 협착 | 선회 반경 내 작업자 접근 | 출입금지 구획, 신호수 배치 |
| 감전 | 충전전로 이격거리 미준수 | 전로 방호관 설치 또는 정전 작업 |

## VI. 결론

1. 크레인 작업의 안전은 **정격하중표 확인 → 아웃트리거 완전 전개 →
   지반 지지력 확보 → 신호수 단일화**의 네 가지를 지키는 것으로
   대부분의 중대재해를 예방할 수 있다.

2. 특히 **정격하중은 작업반경의 함수**로 급격히 감소하므로, 경험이나
   감각에 의한 판단을 배제하고 반드시 하중표를 확인해야 한다.
   과부하방지장치의 임의 해제는 어떠한 경우에도 허용될 수 없다.

3. 관리적 측면에서는 작업계획서 수립과 위험성평가를 형식이 아닌
   **실질적 절차**로 운영해야 하며, 줄걸이 작업자에 대한 자격 관리가
   낙하재해 예방의 핵심이다.

4. 향후 **모멘트 리미터와 연동한 자동 제한 제어, 카메라·AI 기반 접근
   감지 시스템**의 적용이 확대되어, 인적 판단에 의존하던 안전관리가
   시스템적 방호로 전환될 것으로 사료된다.
