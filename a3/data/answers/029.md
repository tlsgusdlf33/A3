# 건설기계 디젤엔진 터보차저의 목적과 특성

meta: 029 | 서술형(25점) | 엔진 및 파워트레인

## I. 개요

### 1. 정의
배기가스의 **잔존 에너지로 터빈을 구동**하고, 동축의 컴프레서로 흡입공기를
압축·과급하여 체적효율을 높이는 배기 터빈 과급기이다.

### 2. 건설기계에서의 필요성
- 동일 배기량으로 **출력 30~40% 증대** → 기체 소형·경량화
- 공기 과잉률 확보로 **완전연소 촉진 → PM(매연) 저감**
- 고지대 작업 시 **공기 밀도 저하 보상** (1,000 m당 출력 약 10% 감소분)
- 배기 에너지 회수로 **연비(BSFC) 5~10% 개선**

## II. 구조 및 작동원리

### 1. 계통도

```
     신기(대기)                              배기가스
        │                                       ▲
        ▼                                       │
   ┌─────────┐                            ┌─────┴────┐
   │컴프레서 │◀═══════ 동축 샤프트 ══════▶│  터빈    │
   │ (흡기측)│         (10만 rpm 이상)     │ (배기측) │
   └────┬────┘                            └─────▲────┘
        │ 압축공기 (150~200℃)                   │
        ▼                                       │
   ┌─────────┐                                  │
   │인터쿨러 │ 공기 냉각 (→ 50~60℃)            │
   └────┬────┘ 밀도 ↑, 충전효율 ↑               │
        ▼                                       │
   ┌──────────────── 엔진 실린더 ───────────────┘
   │   흡기 → 압축 → 연소 → 배기
   └─────────────────────────────────────────
```

### 2. 인터쿨러의 역할

| 구분 | 인터쿨러 없음 | 인터쿨러 있음 |
|---|---|---|
| 흡기 온도 | 150~200℃ | 50~60℃ |
| 공기 밀도 | 낮음 | **약 25% 증가** |
| 충전효율 | 저하 | 향상 |
| NOx 배출 | 높음(연소 최고온도 상승) | **저감** |
| 노킹·열부하 | 위험 | 안정 |

> 과급만 하고 냉각하지 않으면 **단열압축으로 온도가 상승**하여 밀도 이득이
> 상쇄되고 NOx가 급증한다. 과급과 냉각은 한 세트로 서술해야 한다.

### 3. 부스트압 제어

```
  [웨이스트게이트(WGT)]              [가변형상터빈(VGT)]

   배기 ──┬──▶ 터빈               배기 ──▶ ▏▏▏ 가변 베인 ──▶ 터빈
          │                                 ↕ 각도 제어
          └──▶ 바이패스 (방출)
                                    저속: 베인 닫힘 → 유속↑ → 부스트↑
   설정압 초과 시 배기 일부를          고속: 베인 열림 → 배압↓
   터빈을 거치지 않고 방출
                                    → 전 영역 최적 과급, 터보래그 대폭 감소
   구조 단순, 저가                    구조 복잡, EGR 제어와 연동 필수
   저속 터보래그 존재
```

## IV. 문제점 및 대책

| 현상 | 원인 | 점검·대책 |
|---|---|---|
| **출력 저하·흑연** | 에어필터 막힘, 부스트 누설, VGT 고착 | 흡기 차압 확인, 부스트압 실측, 배관 기밀 시험 |
| 오일 소모·백연 | 터보 샤프트 시일 마모 | 흡·배기측 오일 흔적 확인, 터보 교환 |
| 이상 소음(금속음) | 임펠러와 하우징 접촉, 베어링 마모 | 샤프트 유격 측정(축방향 0.1 mm 이내) |
| **소착(Seizure)** | 고온 정지 직후 시동 OFF | **아이들 공회전 3~5분 후 정지** |
| 서징(Surging) | 급감속 시 압축공기 역류 | 블로우오프 밸브 점검 |

### 터보차저 수명을 좌우하는 3대 운전수칙

```
  ① 시동 직후 : 급가속 금지 (30초 이상 아이들)
       → 윤활유가 터보 베어링까지 도달하는 시간 확보

  ② 정지 전   : 고부하 작업 직후 3~5분 아이들
       → 터빈 온도 700℃ → 잔류 오일 탄화(코킹) 방지

       터보 온도
        ▲
     700┤████ 즉시 정지 시 : 오일 순환 정지 → 코킹 → 베어링 소착
        │    ╲
     300┤     ╲──── 아이들 냉각 시 : 안전
        └──────────────▶ 시간

  ③ 오일 관리 : 규정 유종·주기 엄수
       → 터보 베어링은 엔진 내 가장 가혹한 윤활 조건
```

## V. 배출가스 규제와의 관계

| 규제 단계 | 요구사항 | 터보 기술 대응 |
|---|---|---|
| Tier-3 / Stage IIIA | NOx+HC 4.0 g/kWh | WGT + 인터쿨러 |
| Tier-4i / Stage IIIB | PM 0.025 g/kWh | VGT + EGR + DPF |
| **Tier-4F / Stage IV** | NOx 0.4 g/kWh | VGT + Cooled EGR + DPF + SCR |
| **Stage V** | PN(입자 개수) 규제 추가 | 고정밀 VGT + 후처리 통합 제어 |

과급 기술은 단순 출력 향상 수단에서 **배출가스 저감 시스템의 핵심 구성요소**로
역할이 전환되었다. EGR 가스를 재순환시키면서도 필요 산소량을 확보하려면
정밀한 부스트 제어가 전제되기 때문이다.

## VI. 결론

1. 터보차저는 **버려지는 배기 에너지를 회수**하여 출력·연비·배출가스를
   동시에 개선하는 장치로, 현대 건설기계 디젤엔진의 필수 구성요소이다.

2. 성능의 핵심은 과급 자체가 아니라 **인터쿨러에 의한 밀도 회복**과
   **VGT에 의한 전 영역 최적 제어**에 있으며, 저속 터보래그 해소가
   건설기계 작업성에 직결된다.

3. 실무적으로 터보차저 고장의 대부분은 부품 결함이 아니라
   **운전 습관(고온 즉시 정지)과 오일 관리 불량**에서 비롯된다.
   따라서 운전자 교육과 일상점검 항목에 아이들 냉각 절차를 명문화하는 것이
   가장 효과적인 예방 대책이라 판단된다.

4. Stage V 대응을 위해 향후 **전동 터보(e-Turbo)** 및 2단 과급 적용이
   확대되어 터보래그를 근본적으로 해소하는 방향으로 발전할 것으로 사료된다.
