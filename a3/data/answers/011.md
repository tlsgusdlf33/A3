# 건설기계 유압시스템의 기본 원리

meta: 011 | 서술형(25점) | 유압 시스템

## I. 개요

### 1. 유압시스템의 정의
밀폐된 회로 내에서 **작동유의 압력에너지**를 매개로 원동기의 기계적 에너지를
액추에이터의 기계적 일로 전달·제어하는 동력전달 시스템을 말한다.

### 2. 건설기계에서의 적용 의의
- 굴삭기·로더 등은 **좁은 공간에서 수십 톤급 굴착력**을 내야 하므로,
  단위 중량당 출력이 큰 유압 구동이 필수적이다.
- 무단 변속과 원격 조작이 가능하여 **1인 운전으로 다축 복합동작**을 구현한다.
- 릴리프 밸브로 회로 최고압을 제한하므로 **과부하 시 기계 보호**가 자동으로 이루어진다.

## II. 유압시스템의 기본 원리

### 1. 파스칼의 원리 (Pascal's Principle)
밀폐된 용기 내 정지 유체의 한 점에 가해진 압력은 **감소 없이 유체 전부에
같은 크기로, 벽면에 수직으로** 전달된다.

```
        F₁                                   F₂
         ↓                                    ↑
    ┌────┴────┐                        ┌──────┴──────┐
    │ A₁      │                        │ A₂          │
    ├─────────┤                        ├─────────────┤
    │░░░░░░░░░│◀────── 작동유 ───────▶│░░░░░░░░░░░░░│
    └─────────┴────────────────────────┴─────────────┘
         소경 실린더                        대경 실린더

        P = F₁/A₁ = F₂/A₂   →   F₂ = F₁ · (A₂/A₁)
        일의 보존 :  F₁ · S₁ = F₂ · S₂   →  S₂ = S₁ · (A₁/A₂)
```

즉 **면적비만큼 힘은 증폭되지만 행정은 그 역수만큼 감소**하며, 일(에너지)은 보존된다.
이것이 작은 조작력으로 큰 굴착력을 얻는 원리이다.

### 2. 지배 방정식

| 물리량 | 관계식 | 의미 |
|---|---|---|
| 압력 | P = F / A | **부하**가 압력을 결정한다 (펌프가 아니라) |
| 속도 | v = Q / A | **유량**이 액추에이터 속도를 결정한다 |
| 추력 | F = P · A | 실린더 면적이 크면 같은 압력에 큰 힘 |
| 동력 | L = P·Q / 612 | L[kW], P[kgf/cm²], Q[ℓ/min] |
| | L = P·Q / 60 | L[kW], P[MPa], Q[ℓ/min] |

> **답안 포인트** — "압력은 부하가, 속도는 유량이 만든다"는 한 줄을 반드시 쓴다.
> 이 문장 하나로 이후 모든 고장진단 논리가 연결된다.

### 3. 에너지 변환 경로

```
  원동기        유압펌프          배관·밸브         액추에이터
 ┌──────┐     ┌────────┐      ┌─────────┐      ┌──────────┐
 │ 디젤 │────▶│ 기계E → │─────▶│ 압력E   │─────▶│ 압력E →  │
 │ 엔진 │ 회전 │ 압력E   │ 유압  │ 제어·분배│ 유압  │ 기계E    │
 └──────┘ 토크 └────────┘      └─────────┘      └──────────┘
                   η_p≈0.85       η_v≈0.95         η_a≈0.90
                        전체 효율 η ≈ 0.70 ~ 0.75
```

## III. 유압시스템의 구성

```
                    ┌──── 릴리프 밸브 (최고압 제한)
                    │        ▲
                    │        │
  ┌────┐   ┌────┐   │   ┌────┴─────┐   ┌──────────────┐
  │탱크│──▶│펌프│───┴──▶│ 방향제어 │──▶│ 유압 실린더  │
  │    │   │    │       │  밸브    │   │ (액추에이터) │
  └──▲─┘   └────┘       └────┬─────┘   └──────┬───────┘
     │  ↑스트레이너            │                 │
     └──┴─── 리턴필터 ◀───────┴─────────────────┘
                              복귀 라인
```

| 구분 | 구성요소 | 기능 |
|---|---|---|
| 동력원부 | 유압펌프, 원동기 | 기계에너지 → 압력에너지 변환 |
| 제어부 | 압력·유량·방향 제어밸브 | 힘·속도·방향의 3요소 제어 |
| 구동부 | 실린더, 유압모터 | 압력에너지 → 직선/회전 운동 |
| 부속기기 | 탱크, 필터, 어큐뮬레이터, 냉각기 | 저장·여과·축압·방열 |

### 제어 3요소
- **압력 제어** = 힘의 제어 (릴리프, 리듀싱, 시퀀스 밸브)
- **유량 제어** = 속도의 제어 (미터인, 미터아웃, 블리드오프)
- **방향 제어** = 운동방향 제어 (스풀식 4포트 3위치 밸브)

## IV. 유압시스템의 특징

| 구분 | 내용 |
|---|---|
| **장점** | 소형·경량으로 大출력 (출력밀도 공압의 10배 이상) |
| | 무단 변속 및 정밀 속도제어 용이 |
| | 릴리프 밸브에 의한 자동 과부하 보호 |
| | 원격·자동 제어 및 동력 분기 용이 |
| | 작동유가 윤활·방청 기능 겸함 |
| **단점** | 작동유 **오염에 극히 민감** (고장의 70~80%가 오염 기인) |
| | 온도에 따른 점도 변화로 속도 특성 변동 |
| | 누유 시 환경오염 및 화재 위험 |
| | 배관 손실·발열로 효율 저하 (전체 η ≈ 0.7) |

## V. 문제점 및 대책

| 문제 현상 | 주요 원인 | 대책 |
|---|---|---|
| 작동유 오염 | 외부 유입, 내부 마모분, 수분 | 여과도 10㎛ 이하 관리, NAS 9급 이내 유지, 브리더 필터 설치, 정기 오일분석(SOS) |
| 캐비테이션 | 흡입측 부압, 스트레이너 막힘, 점도 과대 | 흡입관 짧고 굵게, 흡입 저항 0.02 MPa 이내, 정기 스트레이너 세척, 적정 유종 선정 |
| 과열 (80℃ 초과) | 릴리프 과다 작동, 내부 누설, 냉각기 불량 | 오일쿨러 코어 청소, 릴리프 설정압 적정화, 탱크 용량 = 펌프 토출량의 3배 이상 |
| 외부 누유 | 시일 경화, 체결 이완, 호스 피로 | 시일 정기 교환, 규정 토크 관리, 호스 굽힘반경 준수 |
| 작동 지연·무력 | 펌프 용적효율 저하, 내부 누설 | 토출압·토출량 실측, 규정값 대비 90% 미만 시 오버홀 |

## VI. 결론

1. 유압시스템의 기본 원리는 **파스칼의 원리에 기초한 압력의 등방 전달**이며,
   "압력은 부하가, 속도는 유량이 결정한다"는 명제가 설계·진단의 출발점이다.

2. 건설기계는 분진·고온·충격이 상존하는 가혹 환경에서 운용되므로,
   원리의 이해보다 **작동유 청정도 관리가 신뢰성을 좌우**한다.
   실무적으로 고장의 70~80%가 오염에 기인하는 만큼, 여과도 관리와
   정기 오일분석을 예방정비 체계에 편입시켜야 한다.

3. 향후 전자유압(EH) 제어와 부하감응(Load Sensing) 시스템의 확대,
   전동화 건설기계의 보급에 대응하여 **에너지 회생형 유압회로** 적용을
   적극 검토할 필요가 있다고 사료된다.
