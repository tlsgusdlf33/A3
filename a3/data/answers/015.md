# 건설기계용 유압펌프의 종류와 특성

meta: 015 | 서술형(25점) | 유압 시스템

## I. 개요

### 1. 유압펌프의 정의
원동기의 **기계적 회전에너지를 작동유의 압력에너지로 변환**하는 기기로,
유압시스템의 동력원에 해당한다.

### 2. 건설기계용 펌프의 요구조건
- 고압화 : 굴삭력 확보를 위해 **35 MPa 이상**의 상용 압력
- 가변 용량 : 부하에 따른 토출량 조절로 연비 개선
- 내오염·내충격성 : 분진·진동이 상존하는 현장 환경
- 고효율 : 전효율 90% 이상 (동력 손실 = 발열 = 연비 악화)

### 3. 분류 체계

```
 유압펌프 ┬─ 비용적형 (원심식) … 저압·대유량, 건설기계 미사용
          │
          └─ 용적형 ┬─ 기어펌프 ┬─ 외접형 ← 건설기계 보조회로
                    │           └─ 내접형
                    ├─ 베인펌프 ┬─ 정용량형
                    │           └─ 가변용량형
                    └─ 피스톤펌프 ┬─ 액시얼형(사판식/사축식) ← 메인펌프
                                  └─ 레이디얼형
```

## II. 유압펌프의 작동원리

### 1. 용적형 펌프의 공통 원리
밀폐 공간의 **체적 변화**로 흡입·토출을 반복한다.

```
   흡입 행정                    토출 행정
 ┌──────────┐                ┌──────────┐
 │  ┌────┐  │                │      ┌──┐│
 │  │    │  │ 체적 증가       │      │  ││ 체적 감소
 │  │ ▼  │  │ → 부압 → 흡입   │   ◀──│▲ ││ → 가압 → 토출
 │  └────┘  │                │      └──┘│
 └──────────┘                └──────────┘
```

### 2. 주요 계산식

| 항목 | 식 | 비고 |
|---|---|---|
| 이론 토출량 | Q_th = q · N / 1000 | q[cc/rev], N[rpm], Q[ℓ/min] |
| 실 토출량 | Q = Q_th · η_v | η_v : 용적효율 |
| 용적효율 | η_v = Q_실제 / Q_이론 | 신품 0.95 이상, **0.85 미만 시 오버홀** |
| 전효율 | η = η_v · η_m | 피스톤펌프 0.90~0.95 |
| 소요동력 | L = P·Q / (612·η) | L[kW], P[kgf/cm²], Q[ℓ/min] |

### 3. 액시얼 피스톤 펌프(사판식)의 용량 가변 원리

```
        사판각 α 大 (최대 토출)            사판각 α 小 (최소 토출)
    ┌─────────────────┐              ┌─────────────────┐
    │  ╱│ 피스톤 행정 大│              │  │ 피스톤 행정 小 │
    │ ╱ │  ↕↕↕↕        │              │  │   ↕           │
    │╱ α│              │              │ α│               │
    └─────────────────┘              └─────────────────┘
       실린더블록 회전                    실린더블록 회전

    q = A · D · tan α · Z
    A: 피스톤 단면적, D: 피치원 지름, Z: 피스톤 수
    → 사판각 α 만 바꾸면 회전수 변경 없이 토출량 무단 조절
```

## III. 종류별 특성 비교

| 구분 | 기어펌프 | 베인펌프 | 피스톤펌프 |
|---|---|---|---|
| 최고 사용압력 | 17~21 MPa | 14~21 MPa | **35~42 MPa** |
| 전효율 | 0.80~0.85 | 0.80~0.88 | **0.90~0.95** |
| 용량 가변 | 불가(정용량) | 가변형 존재 | **가변 용이(사판각)** |
| 회전수 범위 | 넓음 | 중간 | 넓음 |
| 내오염성 | **매우 우수** | 불리(베인 고착) | 불리(정밀 간극) |
| 소음 | 큼 | **작음** | 중간 |
| 구조·정비성 | 단순·저가 | 중간 | 복잡·고가 |
| 맥동률 | 큼 | 작음 | 중간(홀수 피스톤) |
| 건설기계 적용 | 파일럿·조향·팬 구동 | 공작기계 위주 | **굴삭기 메인펌프** |

### 굴삭기 메인펌프에 피스톤펌프를 쓰는 이유
1. 굴착 시 **35 MPa 이상 고압**이 필요 — 기어·베인펌프로는 불가
2. 붐/암/버킷/선회의 부하가 순간순간 달라 **가변 용량**이 필수
3. 무부하 시 사판각을 줄여 **연료 소비를 직접 절감** (엔진 부하 저감)

## IV. 문제점 및 대책

| 현상 | 원인 | 대책 |
|---|---|---|
| 토출량 저하 | 내부 마모(간극 증대), 사판 제어 불량 | 용적효율 실측, 0.85 미만 시 오버홀 |
| 이상소음·진동 | **캐비테이션**, 공기 혼입, 베어링 손상 | 흡입 저항 0.02 MPa 이내, 흡입관 기밀 점검 |
| 조기 마모 | 작동유 오염(NAS 10급 초과) | 여과도 10㎛ 이하, 리턴·흡입 필터 주기 관리 |
| 과열 | 릴리프 상시 작동, 내부 누설 | 설정압 적정화, 오일쿨러 코어 청소 |
| 드레인량 증가 | 슈·실린더블록 간극 확대 | 드레인 유량 측정(규정치의 2배 초과 시 교환) |

### 캐비테이션 방지 설계 기준

```
  흡입측 압력
   ▲
   │ 대기압 (0.1 MPa) ─ ─ ─ ─ ─ ─ ─
   │      ╲
   │       ╲── 허용 한계 (−0.02 MPa)
   │        ╲
   │─ ─ ─ ─ ─╲─ ─ ─ ─ 포화증기압
   │          ╲░░░░ 기포 발생
   └────────────────────────▶
      탱크  스트레이너  펌프

  · 흡입관은 짧고 굵게, 엘보 최소화
  · 스트레이너 여과도 100~150㎛, 용량은 펌프 토출량의 2배
  · 작동유 점도 : 시동 시 1000 cSt 이하, 정상 시 15~35 cSt
```

## V. 선정 시 고려사항

1. **압력** — 회로 최고압의 1.25배 이상 정격을 갖는 기종 선정
2. **유량** — 액추에이터 소요 속도 v = Q/A 로부터 역산
3. **가변 여부** — 부하 변동이 크면 가변용량형(에너지 절감 20~30%)
4. **구동 조건** — 엔진 직결 회전수, 회전 방향, 커플링 형식
5. **작동유 적합성** — 난연성 작동유 사용 시 펌프 허용 압력 감액 고려

## VI. 결론

1. 건설기계용 유압펌프는 고압·가변 요구에 따라 **액시얼 피스톤 펌프가 메인펌프의
   표준**으로 자리잡았으며, 기어펌프는 파일럿·조향 등 보조회로에 병용된다.

2. 펌프의 수명을 결정하는 것은 설계가 아니라 **작동유 청정도와 흡입 조건**이다.
   특히 캐비테이션은 소음으로 시작해 침식·파손으로 진행되므로,
   이상소음 발생 시 즉시 흡입계통을 점검하는 것이 원칙이다.

3. 최근 **부하감응(Load Sensing) 및 전자비례 제어 펌프**가 확대 적용되어
   필요한 만큼만 토출함으로써 연비를 10~20% 개선하고 있으며,
   전동화 건설기계에서는 모터 회전수 제어와 결합한 가변 시스템으로
   발전할 것으로 판단된다.
